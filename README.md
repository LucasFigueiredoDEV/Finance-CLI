# Financial Management System

A financial management system developed in **pure Java**, running through a command-line interface (CLI).

The project aims to practice and strengthen Java fundamentals and object-oriented programming concepts through a practical application for managing personal finances.

## Features

* Register income
* Register expenses
* List transactions
* View financial summary
* Organize transactions by categories
* Interact with the system through a terminal-based menu

## Learning Goals

This project was developed with a focus on learning and consolidating fundamental Java concepts, including:

* Object-Oriented Programming (OOP)
* Classes and objects
* Encapsulation
* Methods and attributes
* Collections
* Exception handling
* Control structures
* Data input and output
* Separation of responsibilities
* Development best practices

The project will be gradually improved as new Java concepts are studied and applied.
